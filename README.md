## About The Project

This project is for our Applied Machine Learning (CST8504) Assignment1 a Prediction Dashboard.

The dataset is the Framingham Heart Study dataset, which you can download from here:
https://www.kaggle.com/datasets/noeyislearning/framingham-heart-study

We are using three machine learning models to try to predict the 10 year likelihood of chronic heart disease.

The models are: decision Tree, Random Forest, and  DNN

<!-- REQUIREMENTS -->
## Requirements
The dashboard requires streamlit. Our application is written in python.

Docker is also required for the deployment.

<!-- DEPLOYMENT -->
## DEPLOYMENT
To run the dashboard, you will need docker. Run this command and point your browser to localhost:8501

    docker compose up
